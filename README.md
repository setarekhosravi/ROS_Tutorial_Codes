# ROS1 Tutorial Repository  

## Overview  
This repository contains structured materials and hands-on exercises for learning Robot Operating System 1 (ROS1). The tutorial covers core ROS1 concepts, including nodes, topics, parameters, services, messages, actions, rosbag, and creating custom services, messages, and launch files. The knowledge gained from this tutorial helped me to contribute to real-world applications.

## 1. Introduction  
This section provides an introduction to ROS1, its importance in robotics, and its role in autonomous and aerial systems. The tutorial is based on the Udemy course by Edouard Renard and supplemented by materials from TU Delft’s ROS1 course.  

## 2. ROS Basics  
This section covers the ROS1 framework, installation, and essential command-line tools. Topics include:  
- ROS file system  
- Workspace setup  
- Using `roscore`, `rosrun`, and `roslaunch`  

## 3. ROS Topics and Messages  
ROS topics allow nodes to communicate via message passing. This section explores:  
- Publishing and subscribing to topics  
- Message types and formats  
- Using `rostopic` for debugging  

## 4. ROS Nodes and Parameters  
This section introduces ROS nodes and parameter servers:  
- Creating and managing ROS nodes  
- Using the ROS parameter server  
- Launching multiple nodes  

## 5. Services and Actions  
ROS services provide request-response communication, while actions enable asynchronous execution. Topics covered include:  
- Defining and calling services  
- Implementing ROS actions  

## 6. Working with rosbag  
`rosbag` is used for recording and replaying ROS data. This section covers:  
- Recording topics  
- Playing back recorded data  

## 7. Creating Custom Messages and Services  
This section demonstrates how to define custom message and service types for specific applications.  

## 8. Launch Files and Package Management  
ROS launch files simplify complex system execution. Topics include:  
- Writing and using `.launch` files  
- Managing ROS packages  

## 9. Applications in Robotics  
The knowledge from this tutorial helps me to contribute to an aerial robotics project, involving real-world applications such as drone control, perception, and navigation.
