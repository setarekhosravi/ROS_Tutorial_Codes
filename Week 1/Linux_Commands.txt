! different modes:
>> Esc: go to normal mode
>> i: go to insert mode and write
! How to save? 
! Go to normal mode by Esc
! Enter : it means you want to write a command
! Then enter w means write file
! How to quit from vim?
! By :q
! Up: k, Down: j, Left: h, Right: l
! Other sortcuts are in vim cheatsheet
! SHIFT + a: go to end of the line and insert mode
! In normal mode:
! Copy: yy 
! Paste: p
! delete: dd
! You can combine the commands
>> press o in normal mode to insert a new line
>> press shift + o to insert a new line above
>> press yy in normal mode to copy a line
>> press pp in normal mode to paste a line
>> press y + w in normal mode to copy a word
>> press y + e in normal mode to copy a word
>> press u in normal mode to undo
>> press ctrl + r in normal mode to redo
>> press x in normal mode to delete a character
>> press :!date in normal to see current date
>> press :r!date in normal to see current date in editor
>> press :x save and quit
>> press :wq save and quit
>> press :wq! force save and quit
For learning vim you should use complete courses.

################redirection,Sed,Pipe#######################
###########################################################
>> wc -l *.txt
OUTPUT: show number of lines in all .txt files in current directory
>> wc -l *.txt | sort -n
OUTPUT: show number of lines in all .txt files in current directory and sort them
>> wc -l *.txt | sort -n | head -n5
OUTPUT: show number of lines in all .txt files in current directory and sort them and show first 5 lines
>> wc -l *.txt | sort -n | head -n5 | grep -v "names"

! redirect is done by > and <
>> ls ali 2> ali.txt
OUTPUT: redirect output error to ali.txt
>> ls ali &> ali.txt
OUTPUT: redirect output 1 (std output) and 2 (error output) to ali.txt
>> ls ali &>> ali.txt
OUTPUT: append redirect output to ali.txt
>> cat < file1.txt > file2.txt
OUTPUT: copy content of file1.txt to file2.txt

####################Sed###########################
##################################################
>> echo "Setare Khosravi is student, Setare is 24" | sed 's/Setare/Alireza/'
OUTPUT: replace the first "Setare" with "Alireza"
>> echo "Setare Khosravi is student, Setare is 24" | sed 's/Setare/Alireza/g'
OUTPUT: replace all "Setare" with "Alireza"
>> echo "Setare Khosravi is student, Setare is 24, setare is here" | sed 's/Setare/Alireza/gi'
OUTPUT: replace all "Setare" with "Alireza" and ignore case sensitivity
>> echo "Setare Khosravi is student, Setare is 24, setare is here, setae is fine" | sed -r 's/Seta.?e/Alireza/gi'
OUTPUT: replace all "Setare" with "Alireza" and ignore case sensitivity and match with regex
>> echo "Setare Khosravi is student, Setare is 24, setare is here" | sed -e 's/Setare/Alireza/gi' -e 's/24/20/'
OUTPUT: replace all "Setare" with "Alireza" and ignore case sensitivity and replace "24" with "20"
